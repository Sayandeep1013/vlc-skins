## VLC Install

1. Copy a `.vlt` file into VLC's `skins` folder.
2. Open VLC.
3. Go to `Tools -> Preferences -> Interface`.
4. Select `Use custom skin`.
5. Choose the `.vlt` file.
6. Save and restart VLC.
